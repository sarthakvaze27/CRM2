Customer CRM for WooCommerce
============================
1. Copy .env.example to a new file named .env and fill in WOO_URL, WOO_KEY, WOO_SECRET.
2. Install requirements:   pip install -r requirements.txt
3. Start the app:          python app.py
4. Open http://127.0.0.1:5000 and click "Sync from WooCommerce".
